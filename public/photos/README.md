# Panduan Foto (Photo Assets)

Aplikasi ini sudah langsung berjalan out-of-the-box menggunakan foto aesthetic Unsplash berkualitas tinggi sebagai fallback otomatis.

Jika kamu ingin memakai foto pribadimu sendiri, cukup simpan foto dengan nama berikut di folder ini (`public/photos/`):

1. **`gate.jpg`**: Foto di layar kunci (Phase 0).
2. **`match-1.jpg`**, **`match-2.jpg`**, **`match-3.jpg`**, **`match-4.jpg`**: 4 foto untuk mini-game Memory Polaroid Match (Phase 1).
3. **`gallery-1.jpg`**, **`gallery-2.jpg`**, **`gallery-3.jpg`**, **`gallery-4.jpg`**, **`gallery-5.jpg`**: Foto-foto untuk album kenangan polaroid scrapbook di Phase 4.

Semua teks caption, tanggal kenangan, dan pesan dapat disesuaikan dengan sangat mudah di file:
`config/birthdayData.ts`
